## 修改前研究与根因

- 完整研究：`docs/repair/round2/research/R2-01.08.md`；优先使用 MoneyPrinterTurbo 上游、SQLite、WHATWG、HTTP、MDN 与 Node.js 一手资料。

## 修复

- 最终渲染响应保留旧 `id` 兼容字段，新增明确 `wrapperId`；`assetId` 唯一用于注册表、预览/下载 URL、响应头和 DOM 数据属性。
- 页面显式保存 `finalWrapperId` 与 `finalAssetId`，并拒绝 API 资产 ID 与预览 URL ID 不一致的结果。
- 最终资产端点正确支持首段、后缀和开放尾段单范围；畸形、多范围、零后缀和越界统一返回准确 `416`。
- 相同最终资产标记未变化时不再重建播放器节点，防止轮询或重复渲染把真实播放重置为暂停。
- 两项浏览器回归改为自包含唯一 handoff，验证真实 API、SQLite、媒体、物理下载、服务重启、fresh Chrome 与精确失败清理。
