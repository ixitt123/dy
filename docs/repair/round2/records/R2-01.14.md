## 根因与修复

- `ui-server.mjs` 新增受本机 Host 边界保护的身份端点，返回固定服务标识、规范项目根、规范入口、随机实例 ID、PID、完整 commit、入口 mtime、启动时间、ready 与真实 URL；不返回 Cookie、Token、设置或其他秘密。
- `launch-ui.mjs` 只接受本机 HTTP URL；复用前逐项校验身份端点、项目根、入口、commit、PID 文件、PID 存活、实例 ID、ready、URL 与源文件 mtime。
- 任一字段不符时只清理当前工作树的陈旧 URL，不终止无法证明归本项目所有的进程，并启动当前项目实例。
- `ui-server.mjs` 的 PID 锁复用路径也执行相同身份校验；身份错误时以所有者 PID 一致性保护的方式清理陈旧运行状态并重新获取锁。
- 既有日志/轮转和页面生命周期测试升级为身份感知契约，保留 R2-01.12 与 R2-01.13 的有效行为。
