## 修复

- Kinetic 受控文件端点声明 `Accept-Ranges: bytes`；合法单范围返回准确 `206`、`Content-Range`、`Content-Length` 和包含端点的字节流。
- 畸形、多范围、零后缀和越界范围返回 `416` 与 `Content-Range: bytes */<size>`；保留原路径解析、允许目录、MIME、下载文件名和 `no-store` 边界。
