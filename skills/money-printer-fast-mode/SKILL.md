# MoneyPrinter 快速素材模式

## 目标

在保留标准模式的同时，为快速模式生成更少、更长、按文案顺序排列的实拍素材。

## 规则

- 将相邻字幕按时间合并为语义分镜组。
- 每组目标时长约 12–20 秒；60 秒视频通常规划 3–5 组。
- 每个分镜组只生成一个英文实拍素材检索词。
- 素材时长覆盖音频后立即停止下载，不下载额外批次。
- 素材按分镜顺序裁剪使用，不循环同一素材补足全片。
- 最终视频始终使用已确认的 TTS 音频。
- 动态大字特效由用户显式开启，默认关闭。
- 输出使用工作台当前统一下载目录。
